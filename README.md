# MIRA Brand Portfolio

A static portfolio showcasing the MIRA brand concept, logo identity, launch post, and promotional poster.

## Live site

https://dondonmarcos1499-wq.github.io/portfolio/

## Local preview

Open `index.html` in a browser. The site uses relative asset paths and requires no build step.

## Deployment

GitHub Actions deploys the site to GitHub Pages whenever changes are pushed to `main`. You can also start a deployment from the **Actions** tab.
